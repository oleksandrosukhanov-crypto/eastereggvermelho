# Pill reminders

Щоденні нагадування в Telegram (наприклад, випити таблетки чи зробити процедуру),
без окремого сервера — через GitHub Actions за розкладом.

## Як це працює

- `reminders.json` — список нагадувань: час (Europe/Lisbon) і текст.
- `send_reminders.py` — перевіряє поточний час у Лісабоні й надсилає ті
  нагадування, чий час збігається.
- `.github/workflows/reminders.yml` — запускає скрипт кожні 15 хвилин.

## Налаштування (один раз)

1. Створи бота через **@BotFather** в Telegram (`/newbot`), збережи токен.
2. Напиши боту будь-яке повідомлення, тоді відкрий у браузері
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates` і знайди `"chat":{"id": ...}`.
3. У репозиторії: **Settings → Secrets and variables → Actions** — додай:
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`
4. **Важливо:** розклад GitHub Actions спрацьовує лише на дефолтній гілці
   (`main`). Після мерджу цих змін у `main` нагадування почнуть приходити
   автоматично.

## Як додати новий препарат або новий час

Відредагуй `reminders.json`, додавши новий об'єкт у масив, наприклад:

```json
[
  { "time": "07:30", "message": "Час випити креатин та інші таблетки 💊" },
  { "time": "21:00", "message": "Вечірні вітаміни" }
]
```

Часи мають бути кратні 15 хвилинам (00, 15, 30, 45) — саме з таким кроком
запускається перевірка. Комітиш і пушиш у `main` — окремо змінювати воркфлоу
не потрібно.

## Перевірка вручну

У вкладці **Actions → Pill reminders → Run workflow** можна запустити
розсилку вручну, не чекаючи розкладу.
